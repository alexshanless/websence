# The answer engines, named explicitly. The wildcard above already allows
# them, but naming them means a later blanket block cannot shut them out by
# accident, and anyone reading this file can see the decision was deliberate.
#
# These are one group, not eleven. A crawler obeys only the most specific
# group that names it and ignores the wildcard entirely, so the preview rules
# have to be repeated here or they would stop applying to exactly these bots.
#

# a page someone asked about, and the Claude, Perplexity and Apple agents
# split the same three ways. Blocking one removes this site from that
# surface. Do not add a Disallow below without meaning it.
